# AI에 넣기 전 가림 도구

고객 이름·전화·이메일 같은 민감정보를 번호로 바꾼 뒤 AI에 주고, AI가 준 결과는 다시 실제 정보로 되돌리는 도구입니다.
파일 하나(`개인정보_가림도구.html`)로 되어 있고, 설치 없이 더블클릭하면 브라우저에서 열립니다. 넣은 자료는 컴퓨터 밖으로 나가지 않습니다.

## 쓰는 순서

처음 열면 암호를 정합니다. 그다음부터는 열 때마다 암호를 넣어야 도구를 쓸 수 있습니다. 바꾼 기록은 이 암호로 잠근 상태로만 저장되고, 내보낸 파일도 같은 암호로 잠겨 있습니다. **암호를 잊으면 바꾼 기록을 열 수 없고, 이미 번호로 바꾼 자료도 되돌릴 수 없습니다.** 원본을 보관하는 곳에 함께 적어 두세요.

화면은 네 부분입니다.

1. **자료 넣기** — 파일이나 폴더를 끌어다 놓으면 민감정보 후보가 몇 건인지 보여 줍니다. "번호로 바꾸기"를 누르면 `김하늘 → 고객_0001`처럼 바꾼 사본을 내려받습니다.
2. **바꾼 기록** — 무엇을 어떤 번호로 바꿨는지 도구가 적어 둔 목록입니다. 펼쳐서 볼 수 있고, 내보내거나 가져올 수 있습니다.
3. **원상 복귀** — AI가 준 결과를 넣으면 번호가 있던 자리를 실제 정보로 되돌립니다.
4. **보안 규칙** — 우리 회사 규칙 세 줄과 다음에 할 일 목록입니다.

AI에 일을 시킬 때는 사본만 주고, "고객_0001 같은 번호는 모양을 바꾸지 말고 그대로 써 줘"를 덧붙입니다.

## 받는 방법

- **복제(클론):** `git clone https://github.com/jch2100/mask-before-ai.git`
- **파일만 내려받기:** 이 페이지 위쪽의 초록색 "Code" 버튼 → "Download ZIP"을 누르고 압축을 풉니다.

받은 뒤 `개인정보_가림도구.html`을 더블클릭하면 됩니다. 설치할 것은 없습니다.

## 연습자료 (모두 가상 자료)

| 파일 | 확인할 것 |
|---|---|
| `연습자료/고객명단.csv` | 이름 열이 자동으로 선택되고, 전환 뒤 줄 수 11과 금액 합계 55,000이 그대로인지 |
| `연습자료/상담메모.txt` | 고객명단을 먼저 전환한 뒤 넣으면 박서연·최민준은 찾지만 **한지우는 놓칩니다.** 도구의 한계를 직접 확인하는 자료입니다 |
| `연습자료/제품소개.txt` | 후보 없음으로 나오는지 |

## 실행 전 확인 (받은 코드를 믿기 전에)

1. 이 폴더를 Codex로 열고 묻습니다: "개인정보_가림도구.html이 인터넷으로 무언가를 보내거나 받아 오는 부분이 있는지 확인해 줘."
2. 파일 맨 위에 `Content-Security-Policy`로 시작하는 줄이 있는지 봅니다. 이 화면이 인터넷으로 무엇이든 보내거나 받는 것을 브라우저가 막게 하는 선언입니다. 이 줄이 지워진 파일은 쓰지 않습니다.
3. 와이파이를 끄고 연습자료로 체크·전환·복원이 되는지 직접 해 봅니다.

## 우리 회사 것으로 고치기 (Codex 요청문)

> 개인정보_가림도구.html 맨 위의 "회사에 맞게 고치는 곳"만 수정해 주세요. 다른 부분은 건드리지 마세요.
> 1. COMPANY를 "[우리 회사 이름] · AI에 넣기 전 가림 도구"로 바꿔 주세요.
> 2. RULES 세 줄을 다음으로 바꿔 주세요: [규칙 1] / [규칙 2] / [규칙 3]
> 3. PATTERNS에 우리 회사 [사번 / 고객번호] 형식을 한 줄 추가해 주세요. 형식 예: [예: EMP-12345]
> 인터넷 연결이 필요한 것은 넣지 마세요. 고친 뒤 연습자료 폴더의 파일로 체크·전환·복원이 그대로 되는지 확인하는 방법을 알려 주세요.

## 한계

- 찾은 것만 바꿉니다. 처음 보는 이름, 주소, 단가·계약 조건 같은 영업비밀은 찾지 못합니다.
- CSV·TXT·MD만 읽습니다. 한글·엑셀·PDF는 "검사 못 함"으로 표시됩니다.
- "바꾼 기록"(김하늘 ↔ 고객_0001 같은 짝 목록)은 그 컴퓨터의 그 브라우저에만 있습니다. 브라우저 기록을 지우거나 컴퓨터를 바꾸기 전에 "바꾼 기록 내보내기"를 하세요.
- 되돌리기는 번호가 있던 자리만 바꿉니다. AI가 다른 칸을 고치거나 열을 추가해도, 파일 이름이 달라져도 번호만 남아 있으면 되돌릴 수 있습니다.
- 같은 이름인 두 사람은 같은 번호가 됩니다.
- 이름을 번호로 바꾼 자료도 개인정보로 다뤄야 합니다. 회사 기준이 우선합니다.
- 원본과 이 도구는 AI 작업 폴더 밖에 두고 씁니다.
